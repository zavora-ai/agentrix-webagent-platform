{#- The decision contract for an operator action (ADR-014): exactly what happens on approval. `e` is access::Effect. Returned as a fragment to the action island. -#} {%- set a = e.action -%}

If you approve, exactly this happens

    {%- if a.action == "break-glass" %}
  • Break-glass on {{ e.domain }} waits for a second person: someone else who holds {{ e.second_role }}.
  • When they sign, the two of you can read its pages, releases, jobs and receipts for {{ e.hours }} hour. Read only: nothing on the site can change.
  • The owner gets a receipt at that moment, with your reason: “{{ a.reason }}”.
  • Both approvals go in the operator ledger. The request lapses if nobody signs within 30 minutes.
    • {%- elif a.action == "break-glass-second" %}
  • Break-glass on {{ e.domain }} opens now, until about {{ e.ends_words }}. {{ e.first_name }} ({{ e.first_role }}) and you can read its pages, releases, jobs and receipts. Read only.
  • The owner gets a receipt now, with the reason.
  • Either of you can close it sooner; it closes itself after one hour.
    • {%- elif a.action == "hold" %}
  • {{ e.domain }} goes on platform hold now. {% if a.mode == "notice" %}Visitors see a neutral “This site isn't available right now” page.{% else %}Visitors can still read it; Ask, forms and the agent door pause.{% endif %}
  • The owner gets a receipt with your reason: “{{ a.reason }}”. The owner can't lift it; an operator lifts it.
    • {%- if not e.holds_enforced %}
  • On this build the hold is recorded and receipted, but the edge doesn't enforce it yet.
    • {%- endif %} {%- elif a.action == "invoice-run" %}
  • {{ e.run.drafts|length }} invoice{{ "" if e.run.drafts|length == 1 else "s" }} for {{ e.run.period }} are issued now, {{ (e.run.total_cents * 10000)|usd }} in all, numbered INV-{{ e.run.period }}-0001 onward.
  • Each is the plan's price and nothing else: no owner has raised their AI cap, so no usage is billed.
  • PayPal collects each one on its subscription's schedule, and its payments mark them paid here.
  • An invoice is never deleted. A mistake is put right with a credit note.
    • {%- elif a.action == "lift" %}
  • The platform hold on {{ e.domain }} is lifted now and the site serves as before.
  • The owner gets a receipt saying so.
    • {%- endif %}
Approved by:{{ e.operator }}recorded in the operator ledger
