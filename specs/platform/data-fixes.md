# Fixes to Brick 1's tables (W8, from 03-data.md §2.4)

Status: proposals, Sun 8 Nov 2026, by W8 (Platform core); owners' answers folded in at
08:30 EAT. W6's rows (3 to 7) and W4's (10 to 12) are Horizon 2, after the freeze. Each table has one owner (03 §4.3);
the owner writes the migration in its own migrator and range. The SQL below is a sketch to start
from. Every change is additive or a rebuild with the same columns and a copy check, so a binary
built before it still runs (how-we-work.md, Migrations). Done by W8 already: `usage`
(0801, open purposes and providers, units, WebAgent, job, process, reserved) and
`visit_counts` (0800, 0803).

Existing cards are covered for erasure by `agentrix_store::subject::ControlSubjectData` (redacts name, email, phone; W8, done).
