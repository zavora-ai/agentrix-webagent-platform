# The first release (deprecated)

This folder is the spec of Agentrix's first release: the single-node profile that moved the first
website through sealed rooms on Vultr and proved the containment gauntlet. It is kept for its
history and for the design references in `deploy/` and the code (design §, R and S numbers).

It is no longer the plan. The Agentrix WebAgent Platform is specified in [`specs/platform/`](../platform/),
starting at [`00-plan.md`](../platform/00-plan.md), and that is what runs at https://agentrix.website.
