Reviewed, so it counts

Wanjiru approved with the card open, so the approval is reviewed and counts toward Orders' promotion. A one-tap approval from WhatsApp would work but wouldn't count (07 §5.3).

One door for money

The PayPal order is created only by the Effects Gateway, for exactly the approved amount, and only after the approval. Verified webhooks post each payment and fee to the books. No WebAgent holds PayPal credentials (08 §4.2, ADR-004).
