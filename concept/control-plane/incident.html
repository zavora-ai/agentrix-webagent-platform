On call, in your pocket

WhatsApp can acknowledge and ask for evidence. Approvals happen in the console.

The SRE WebAgent pages the on-call person where they already are. WhatsApp can acknowledge, ask for evidence, or extend a lever the SRE already pulled. Creating a billable resource, a platform hold on a customer, restoring data or break-glass opens the console for a passkey, or an authenticator code without one: the same decision contract owners have.

Levers, not keys

The SRE WebAgent holds an operator capability token for reversible levers in this cell. It holds no Vultr key. Creating the subscription is an effect the Effects Gateway runs only with the commander's signature.
