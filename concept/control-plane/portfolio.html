The client owns the site

Studio Mwangaza's access to each site is a grant from that site's owner, approved with a passkey or an authenticator code and revocable at any time. A client can export or leave without the agency's consent.

08-control-plane §2.1, §2.5

One import queue, fairly shared

An agency's bulk import and a single owner's Move share the Migration Factory under fair-share scheduling. The crawler stays polite fleet-wide, one request at a time per origin.

08-control-plane §3.4

White-label, honestly

Console, emails, status page and footer can carry the agency's brand. AI disclosure, crawler identity and receipts always name the real operator chain, so abuse reports and verification stay true.
